Exercício 01: Laço Para Clássico

Utilizando a estrutura controlada para, desenvolva uma rotina automática que exiba todos os múltiplos de 5 no intervalo de 0 até 50.

Mostrar Gabarito

    }
  }
}

Exercício 08: Busca de Elemento no Vetor

Exercício 12: Soma da Diagonal Principal

programa {

    inteiro mat[2][2] = {{5, 3}, {2, 9}}, soma = 0

    }

  }
}

Exercício 13: Matriz de Notas de Alunos

Mostrar Gabarito 
programa {

    real boletim[2][3] = {{8.0, 6.0, 0.0}, {5.0, 4.0, 0.0}}
    para(inteiro l=0; l<2; l++) {

    }
  }
}

Exercício 14: Função de Fatorial

Escreva uma funcao que receba um número inteiro por parâmetro, calcule o seu fatorial e retorne o resultado.

Mostrar Gabarito 
programa {
  funcao inteiro fatorial(inteiro n) {
    inteiro f = 1

  }

  funcao inicio() {
    escreva("Fatorial de 5 é: ", fatorial(5))
  }
}

Exercício 17: Vetor Ordenado (Bubble Sort)

Insira 3 números em um vetor e organize-os usando laços para estruturados em ordem crescente.

Mostrar Gabarito 
programa {
  funcao inicio() {
    inteiro v[3] = {9, 2, 5}, aux
    para(inteiro i=0; i<3; i++) {
      para(inteiro j=i+1; j<3; j++) {
        se(v[i] > v[j]) {
          aux = v[i]
          v[i] = v[j]
          v[j] = aux
        }
      }
    }
    escreva("Ordenado: ", v[0], " ", v[1], " ", v[2])
  }
}
