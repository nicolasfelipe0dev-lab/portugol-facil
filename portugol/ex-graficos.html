Exercício 01: Janela Azul

Escreva um algoritmo que inicialize o modo gráfico e renderize uma janela de tamanho 600x400 preenchida completamente com a cor azul.

Mostrar Gabarito 
programa {
  inclua biblioteca Graficos --> g
  funcao inicio() {
    g.iniciar_modo_grafico(verdadeiro)
    g.definir_dimensoes(600, 400)
    
    enquanto(verdadeiro) {
      g.definir_cor(g.COR_AZUL)
      g.limpar()
      g.renderizar()
    }
  }
}

Exercício 02: Alvo Retangular

Desenvolva um algoritmo que renderize uma janela padrão e desenhe centralizado nela um retângulo preenchido com a cor amarela.

Mostrar Gabarito 
programa {
  inclua biblioteca Graficos --> g
  funcao inicio() {
    g.iniciar_modo_grafico(verdadeiro)
    enquanto(verdadeiro) {
      g.definir_cor(g.COR_AMARELO)
      // Desenha retângulo na pos X=100, Y=100 com 200 de largura e 100 de altura
      g.desenhar_retangulo(100, 100, 200, 100, falso, verdadeiro)
      g.renderizar()
    }
  }
}
