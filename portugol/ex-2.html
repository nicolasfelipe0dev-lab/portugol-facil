Exercício 01: Verificação de Velocidade

Escreva um programa que leia a velocidade de um carro. Se ultrapassar 80 Km/h, exiba uma mensagem dizendo que ele foi multado. Caso contrário, exiba "Boa viagem!".

Mostrar Gabarito 
programa {
  funcao inicio() {
    real velocidade
    escreva("Velocidade do veículo: ")
    leia(velocidade)
    se (velocidade > 80) {
      escreva("Você foi MULTADO por excesso de velocidade!")
    } senao {
      escreva("Boa viagem! Dirija com segurança.")
    }
  }
}

Exercício 04: Cálculo de Média com Situação

Crie um programa que calcule a média de duas notas. Se a média for maior ou igual a 7.0, exiba "Aprovado". Se for menor, exiba "Reprovado".

Mostrar Gabarito 
programa {
  funcao inicio() {
    real n1, n2, media
    escreva("Nota 1: ") leia(n1)
    escreva("Nota 2: ") leia(n2)
    media = (n1 + n2) / 2
    se (media >= 7.0) {
      escreva("Média: ", media, " - Aluno APROVADO!")
    } senao {
      escreva("Média: ", media, " - Aluno REPROVADO!")
    }
  }
}

Exercício 08: Calculadora Básica

Crie uma calculadora simples. O usuário insere dois valores reais e digita um caracter contendo a operação desejada ('+', '-', '*', '/'). Use escolha caso.

Mostrar Gabarito 
programa {
  funcao inicio() {
    real v1, v2
    caracter operacao
    escreva("Valor 1: ") leia(v1)
    escreva("Operador (+ - * /): ") leia(operacao)
    escreva("Valor 2: ") leia(v2)
    
    escolha(operacao) {
      caso '+': escreva("Resultado: ", v1 + v2) pare
      caso '-': escreva("Resultado: ", v1 - v2) pare
      caso '*': escreva("Resultado: ", v1 * v2) pare
      caso '/': escreva("Resultado: ", v1 / v2) pare
      caso contrario: escreva("Operação inválida.")
    }
  }
}

Exercício 15: Análise de Notas Complexa

Refaça o exercício da média adicionando três condições: Média abaixo de 5.0 (Reprovado), Média entre 5.0 e 6.9 (Recuperação) e Média acima de 7.0 (Aprovado).

Mostrar Gabarito 
programa {
  funcao inicio() {
    real n1, n2, media

    media = (n1 + n2) / 2

      escreva("Aprovado!")
    } senao se (media >= 5.0 e media < 7.0) {
      escreva("Recuperação.")
    } senao {
      escreva("Reprovado.")
    }
  }
}

Exercício 16: Descobrindo o Maior Número

Escreva um programa que leia 5 números inteiros dentro de um laço enquanto e no final identifique o maior número digitado.

Mostrar Gabarito 
programa {
  funcao inicio() {
    inteiro c = 1, num, maior = 0
    enquanto (c <= 5) {
      escreva("Digite um número: ") leia(num)

  }
}

Exercício 17: Média de Idades com Flag

Faça um programa que leia a idade de vários alunos. O programa deve parar de ler apenas quando o usuário digitar o número "999". Exiba a média das idades.

Mostrar Gabarito 
programa {
  funcao inicio() {
    inteiro idade = 0, soma = 0, cont = 0
    enquanto (idade != 999) {
      escreva("Digite a idade (ou 999 para parar): ") leia(idade)
      se (idade != 999) {
        soma = soma + idade
        cont = cont + 1
      }
    }
    escreva("Média de idade do grupo: ", (soma / cont))
  }
}

Exercício 18: Classificação de Triângulos

Leia três valores para os lados de um triângulo e classifique-o em: Equilátero, Isósceles ou Escaleno.

Mostrar Gabarito 
programa {
  funcao inicio() {
    real a, b, c
    escreva("Lados do triângulo: ") leia(a, b, c)
    se (a == b e b == c) {
      escreva("Triângulo Equilátero.")
    } senao se (a == b ou b == c ou a == c) {
      escreva("Triângulo Isósceles.")
    } senao {
      escreva("Triângulo Escaleno.")
    }
  }
}

Exercício 19: Analisador de Caixa de Loja

Exercício 20: Jogo de Adivinhação Embutido

  funcao inicio() {
