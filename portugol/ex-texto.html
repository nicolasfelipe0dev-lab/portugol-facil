Exercício 01: Contador de Letras

Faça um algoritmo que leia o nome de uma cidade e exiba na tela quantos caracteres essa palavra possui.

Mostrar Gabarito 
programa {
  inclua biblioteca Texto --> txt
  funcao inicio() {
    cadeia cidade
    inteiro tamanho
    escreva("Digite o nome de uma cidade: ")
    leia(cidade)
    tamanho = txt.numero_caracteres(cidade)
    escreva("Essa cidade possui ", tamanho, " caracteres.")
  }
}

Exercício 02: Gritando no Console

Crie um programa que leia uma frase qualquer do teclado e converta todos os seus caracteres para letras maiúsculas (Caixa Alta).

Mostrar Gabarito 
programa {
  inclua biblioteca Texto --> txt
  funcao inicio() {
    cadeia frase, frase_maiuscula
    escreva("Digite algo: ")
    leia(frase)
    frase_maiuscula = txt.caixa_alta(frase)
    escreva("Texto convertido: ", frase_maiuscula)
  }
}
