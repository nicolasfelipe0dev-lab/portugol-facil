Exercício 01: Sorteio do Dado

Escreva um algoritmo que simule o lançamento de um dado convencional de 6 lados, exibindo o número sorteado de 1 a 6.

Mostrar Gabarito 
programa {
  inclua biblioteca Util --> util
  funcao inicio() {
    inteiro resultado_dado
    escreva("Rolando o dado...\n")
    util.aguarde(1000) // Pausa dramática de 1 segundo
    resultado_dado = util.sorteia(1, 6)
    escreva("Número sorteado: ", resultado_dado)
  }
}

Exercício 02: Contagem Regressiva Interativa

Desenvolva um laço que realize uma contagem regressiva de 5 até 1, fazendo com que o console aguarde exatamente 1 segundo entre cada número impresso.

Mostrar Gabarito 
programa {
  inclua biblioteca Util --> util
  funcao inicio() {
    para(inteiro i = 5; i >= 1; i--) {
      escreva(i, "\n")
      util.aguarde(1000)
    }
    escreva("Fogo!")
  }
}
