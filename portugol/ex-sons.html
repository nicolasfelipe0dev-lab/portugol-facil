Exercício 01: Play em Loop

Construa um algoritmo que carregue uma faixa local de áudio chamada "musica.mp3" e inicie sua reprodução contínua em formato Loop.

Mostrar Gabarito 
programa {
  inclua biblioteca Sons --> s
  funcao inicio() {
    inteiro trilha_id
    trilha_id = s.carregar_som("./musica.mp3")
    s.reproduzir_som(trilha_id, verdadeiro) // verdadeiro ativa o loop continuo
    escreva("Tocando música de fundo...")
  }
}
