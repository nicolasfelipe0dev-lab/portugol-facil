Lógica dos Comandos

Compreenda a estrutura lógica fundamental por trás das palavras-chave que ditam o comportamento do seu algoritmo.

Condicional

se / senao

Cria ramificações na execução do programa. Se uma condição for verdadeira, executa um bloco; do contrário, executa uma alternativa.

Repetição

enquanto

Executa repetidamente um bloco de comandos testando a condição no início. Continua rodando enquanto o teste for verdadeiro.

Repetição

para

Utilizado para repetições onde você sabe antecipadamente o limite exato de vezes que o bloco deve ser iterado por meio de uma variável de controle.

Seleção

escolha caso

Uma alternativa mais limpa e legível a múltiplos "se/senao se" encadeados quando se avalia valores fixos de uma única variável.

Estrutura de controles

faça enquanto

Garante que o bloco de comandos seja executado pelo menos uma vez antes de avaliar a condição. Continua repetindo enquanto o teste para verdadeiro.

Entrada e conhecimento de Dados

Escreva

Exibe informações na tela do usuário, permitindo exibir textos literários, valores armazenados em variáveis ​​ou resultados de expressões.

Entrada e conhecimento de Dados

leia

Interrompe a execução do programa para aguardar uma entrada do usuário via teclado, armazenando o valor digitado em uma variável.

Estrutura Global do Programa

programa

Delimita o escopo principal do código. Funciona como o contêiner obrigatório onde todo o algoritmo em Portugol deve ser desenvolvido.

Estrutura Global do Programa

funcao

Definir um bloco de código reutilizável que execute uma tarefa específica. A "função início" demarca o ponto exato onde começa a execução do programa.

Tipos de Dados e Variáveis

inteiro

Declara variáveis ​​específicas ao armazenamento de números inteiros, ou seja, valores numéricos positivos ou negativos que não possuem casas decimais.

Tipos de Dados e Variáveis

real

Declara variáveis ​​para o armazenamento de números reais. Permite trabalhar com valores que contêm frações ou pontos decimais.

Tipos de Dados e Variáveis

cadeia

Declara variáveis ​​para armazenar sequências de caracteres alfanuméricos, como palavras, frases ou códigos estruturados, sempre delimitados por aspas duplas.

Tipos de Dados e Variáveis

caracter

Declara variáveis projetadas para guardar um único caractere isolado (letra, dígito ou símbolo), delimitado por aspas simples.

Tipos de Dados e Variáveis

logico

Declara variáveis booleanas que podem assumir exclusivamente um de dois valores possíveis: verdadeiro ou falso.

Desvio de Fluxo

pare

Interrompe imediatamente a execução de um laço de repetição ou finaliza um bloco condicional "caso", forçando o programa a ir para a próxima linha fora da estrutura.

Desvio de Fluxo

retorne

Finaliza imediatamente a execução de uma função e envia um valor de resposta de volta para a linha de código que fez a chamada dessa função.

Estrutura de Dados

vetor [ ]

Declara uma estrutura unidimensional capaz de armazenar uma coleção ordenada de múltiplos valores do mesmo tipo de dado sob um único nome.

Estrutura de Dados

matriz [ ][ ]

Declara uma estrutura bidimensional disposta em linhas e colunas (grade), ideal para organizar tabelas de dados do mesmo tipo.
